Vi Advanced Features & Instructions

📄 CV Processing & Classification

Automatic Classification

Vi automatically categorizes CVs into:

  • IT/Tech: Software Engineers, DevOps, QA, Data Scientists
  • Business: Sales, Marketing, HR, Finance
  • Other: General positions

Smart Extraction

Vi extracts and structures:

  • Contact information (email, phone, LinkedIn)
  • Technical skills and tech stack
  • Work experience with timeline
  • Education and certifications
  • Languages and proficiency levels

Batch Processing

  • Upload up to 12 CVs simultaneously
  • Each file can be up to 10MB
  • Process multiple candidates at once
  • Compare and rank candidates

💡 Best Practices

For Best Results

  • Be specific: "Senior React developer with TypeScript" vs "developer"
  • Provide context: Share JD details, team info, company culture
  • Use examples: "Like candidate X but with more Y experience"
  • Iterate: Refine searches based on initial results

Pro Tips

  • Upload JD along with CVs for better matching
  • Ask for comparison tables for multiple candidates
  • Request interview questions based on CV gaps
  • Generate offer letter templates
  • Create candidate portfolios for hiring managers
